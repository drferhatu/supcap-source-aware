# Source-Aware Materials Informatics for Biomass-Derived Carbon Electrodes

Companion code and derived data for the paper:

> **Source-Aware Materials Informatics for Biomass-Derived Carbon Electrodes: Predicting Supercapacitor Capacitance from Precursor and Process Descriptors**
> Ferhat Uçar, Nida Katı, Mohammed Abduljalil Saeed Ahmed
> *Physica Scripta* (IOP Publishing), 2026. Manuscript ID `PHYSSCR-153869` (under review).

The repository contains the full modelling pipeline used to produce the results reported in the manuscript: dataset cleaning, source-aware validation, repeated-split stability envelope, paired Wilcoxon significance testing, and SHAP interpretation for the best-performing feature combination.

## Repository layout

```
├── data/
│   └── cleaned_dataset_195.csv      Ready-to-model dataset (195 samples, 17 predictors).
├── scripts/
│   ├── build_dataset_and_figures.py   Rebuild the cleaned dataset from the raw source and produce
│   │                                  the correlation / biomass-family coverage figures.
│   ├── split_protocol_analysis.py     Random-split vs leave-one-reference-out protocol comparison
│   │                                  using a ridge-regression surrogate.
│   ├── dataset_distributions.py       Target- and process-variable distribution figures.
│   ├── model_performance_ci.py        Repeated-split (n = 30) stability envelope for SVR, Random
│   │                                  Forest, DNN (sklearn MLPRegressor), LightGBM, XGBoost, and
│   │                                  their XGBoost + LightGBM ensemble on the G2 feature block,
│   │                                  followed by paired Wilcoxon tests against XGBoost.
│   └── shap_analysis_g2.py            SHAP interpretation of the XGBoost model on the G2 block.
└── results/
    ├── dataset_summary.txt            195 samples, 17 references, 16 biomass materials, 4 families.
    ├── split_protocol_metrics.csv     Per-repeat metrics for the random-split branch and the
    ├── split_protocol_summary.txt     leave-one-reference-out summary.
    ├── group_fold_metrics.csv         Per-fold metrics for the leave-one-reference-out branch.
    ├── model_ci_g2_raw.csv            Raw per-repeat metrics for every model in the G2 CI study.
    ├── model_ci_g2_summary.csv        Mean ± std across the 30 repeated 80/20 splits.
    ├── model_ci_g2_wilcoxon.csv       Paired Wilcoxon signed-rank test p-values (XGBoost vs. each
    │                                  competitor) on per-split test-set MAE.
    └── shap_g2_xgb_ranking.csv        Mean |SHAP value| ranking for the G2 XGBoost model.
```

Every figure and table in the manuscript can be regenerated by running the corresponding script against the shipped dataset; see [Reproducibility](#reproducibility) below.

## Data provenance

The literature-curated corpus in `data/cleaned_dataset_195.csv` is derived from the supplementary dataset of:

> Zhao *et al.*, *Journal of Energy Storage* **91** (2024) 102400, DOI [10.1016/j.est.2024.112560](https://doi.org/10.1016/j.est.2024.112560), supplementary file `1-s2.0-S2352152X2402560X-mmc1.xlsx`.

The raw Elsevier supplementary spreadsheet is not redistributed here; the derivative CSV in this repository is the cleaned version described in the manuscript (212 raw records → 195 usable rows after row-wise deletion of incomplete records, no imputation).

## Environment

Tested on Python 3.10 with the packages listed in [`requirements.txt`](requirements.txt). A one-line conda setup:

```bash
conda create -n supcap-source-aware python=3.10 -y
conda activate supcap-source-aware
pip install -r requirements.txt
```

## Reproducibility

Run each script from the repository root. Each script reads its inputs from `data/` or `results/` and writes fresh outputs to `results/` (and, for the plotting scripts, to a local `images/` folder that this repository does not track).

```bash
# (1) Rebuild the cleaned dataset + correlation / family-coverage figures (optional; a
#     pre-cleaned copy of the dataset already lives in data/).
python scripts/build_dataset_and_figures.py

# (2) Random-split vs leave-one-reference-out protocol comparison (ridge surrogate).
python scripts/split_protocol_analysis.py

# (3) Target- and process-variable distribution figures.
python scripts/dataset_distributions.py

# (4) Repeated-split stability envelope for all five models + Wilcoxon tests
#     (this is the source of Table 10 and the R2 minor comment on CIs).
python scripts/model_performance_ci.py

# (5) SHAP interpretation of the XGBoost G2 model (Figure 24 in the manuscript).
python scripts/shap_analysis_g2.py
```

All numerical results in the manuscript were produced with a fixed random seed (`20260711`) so the reported values are bitwise reproducible on the same Python / library versions.
